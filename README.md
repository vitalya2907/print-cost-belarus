# Слой — калькулятор домашней 3D-печати

React 19 + Vite 8, русскоязычный интерфейс и расчёты в BYN. Формулы и справочник материалов отделены от React-компонентов; данные формы хранятся в React state.

## Работа

Node.js 22.12+ (проверено на 22.16). `npm ci`, затем `npm run dev`. `npm test` запускает математические и React SSR/state проверки; `npm run build` создаёт dist/, `npm run preview` открывает производственную сборку. dist/ и node_modules/ не хранятся в Git.

## Выбор сборщика

Vite подходит клиентскому калькулятору: простой dev-сервер, JSX и производственная сборка без сервера приложения. Next.js добавил бы ненужные здесь серверные функции, Webpack потребовал бы больше ручной конфигурации; Parcel также подходит, но Vite имеет прямую документированную схему публикации на Pages. Используется стабильная Vite 8.3.2 с Rolldown: стандартная оптимизированная сборка успешно проходит. На проверенном окружении Vite 7 зависал при tree shaking React; отключение оптимизации в итоговом проекте не требуется.

Документация: https://vite.dev/guide/ и https://vite.dev/guide/static-deploy.html.

## Публикация

Сайт: https://vitalya2907.github.io/print-cost-belarus/. Сейчас там одобренная версия из PR #1. React-миграция ожидает пользовательского апрува в новом PR. Pages уже настроен на GitHub Actions. Workflow pages.yml проверяет PR без публикации; после объединения в main устанавливает зависимости по lock-файлу, тестирует, собирает и публикует dist/ через официальные Pages actions. Настроен base /print-cost-belarus/, HTTPS включён.

## Модель расчёта

Количество — независимые одинаковые печати. Для партии на одном столе ввести общие значения слайсера и количество 1. Габариты необязательны, проверяют поле A1 256 мм и не меняют стоимость. Масса до 100 000 г; ползунок расширяется. Источники, дата и допущения видны на сайте и в reports/.
