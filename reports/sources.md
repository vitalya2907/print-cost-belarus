## Брак и модель расчёта

Надёжной универсальной нормы домашнего брака не установлено. 5 / 10 / 20% — сценарии, стартовый 10% явно обозначить как оценку, заменяемую собственной статистикой. Доля завершения неудачной попытки 50% — также сценарное допущение.

Для одной успешной печати:

```text
q = вероятность неудачи, 0 <= q < 1
r = ожидаемое число неудач до успеха = q / (1 - q)
M_success = масса модели + поддержки/кайма + продувка, г
M_failed = доля материала до сбоя * M_success
T_failed = доля времени до сбоя * T_success
C_material = цена_кг / 1000 * (M_success + r * M_failed)
T_expected = T_success + r * T_failed
C_energy = средняя_мощность_Вт / 1000 * T_expected * тариф
C_wear = (цена_принтера - остаточная_стоимость) / ресурс_часов * T_expected
C_maintenance = ставка_обслуживания_BYN_час * T_expected
C_total = C_material + C_energy + C_wear + C_maintenance
          + ручные_расходники + труд + другие_расходы
```

При 10% брака и 50% потерь переменные расходы увеличиваются на 5,56%, а не просто на 10%. При полном расходе каждой неудачи множитель 1/(1-q). Это математическое ожидание при постоянной вероятности неудачи и повторениях до успеха, а не обещание результата отдельного заказа.

Не учитывать брак одновременно в отходах и отдельном резерве. Если вводится полный расход из слайсера, поддержки и продувку повторно не добавлять. Размеры детали сами по себе не определяют массу или время: нужны значения из слайсера либо явно обозначенная грубая геометрическая оценка. Ресурс принтера и обслуживание — редактируемые допущения, без заявления о гарантированном сроке.
