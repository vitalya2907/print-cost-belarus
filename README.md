# Слой — стоимость домашней 3D-печати

Статический калькулятор в BYN, расчёты в браузере без сервера.

## Запуск

`python3 -m http.server 4173 --bind 127.0.0.1 --directory dist`

Открыть http://127.0.0.1:4173.

## Проверка

`node tests/calculator.test.mjs` — независимые математические тесты.

Источники, QA и ревью: reports/. Публикация: Sites, манифест .openai/hosting.json.

## Статус

Реализация и проверки выполнены. Ожидает пользовательского просмотра и апрува. До явного апрува не считать готовым.

## Модель

Количество — отдельные одинаковые печати. При печати партии на одном столе ввести общие значения из слайсера и количество 1. Габариты необязательны и проверяют поле A1 256 × 256 × 256 мм, но не определяют массу или время. Массу можно вводить до 100 000 г; ползунок расширяется при вводе большего значения. PLA/PETG доступны с выбором производителя и собственной ценой. Источники фиксированы на дату проверки; тарифы следует сверить с квитанцией.
