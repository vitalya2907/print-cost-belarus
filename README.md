# Слой — стоимость домашней 3D-печати

Статический калькулятор в BYN, расчёты в браузере без сервера.

## Запуск

`python3 -m http.server 4173 --bind 127.0.0.1 --directory dist`

Открыть http://127.0.0.1:4173.

## Проверка

`node tests/calculator.test.mjs` — независимые математические тесты.

Источники, QA и ревью: reports/. Публикация: Sites, манифест .openai/hosting.json.

## Статус

Реализация и проверки выполнены. Ожидает пользовательского просмотра и апрува. До явного апрува не считать готовым.

## Модель

Количество — отдельные одинаковые печати. При печати партии на одном столе ввести общие значения из слайсера и количество 1. Габариты проверяют поле A1 mini, но не определяют массу или время. Источники фиксированы на дату проверки; тарифы следует сверить с квитанцией.
