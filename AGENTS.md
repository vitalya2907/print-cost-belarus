# Калькулятор стоимости 3D-печати в Беларуси

Общие инструкции: ../../AGENTS.md. Роли: ../../agents/.

React + Vite приложение без backend, русскоязычный интерфейс, BYN. По поручению пользователя фронтенд-агент реализует изменения, затем QA тестирует и ревьювер проверяет. Главный агент интегрирует результат и создаёт отдельный коммит в новой ветке и pull request. Пользователь самостоятельно просматривает и одобряет PR; до его апрува не объединять PR и не отмечать готовым.

Исходники: src/, index.html, vite.config.js. Расчёт: src/calculator.mjs. Проверки: npm test и npm run build. dist/ генерируется и не хранится в Git. Отчёты: reports/. Публикация GitHub Pages через .github/workflows/pages.yml после объединения одобренного PR.

Стоимость за успешную деталь, количество умножает стоимость независимых одинаковых печатей. Масса и время из слайсера; габариты не определяют их. Отходы отдельно от брака. q/(1-q) ожидаемых неудач; доля потерь неудачной печати регулируется.

Не выдавать сценарные допущения за подтверждённые факты. Для источников указывать дату проверки. Чётко различать подтверждённые цены страниц и допущения мощности/ресурса/брака.

Статус: в работе. После QA и ревью запросить апрув пользователя. Не отмечать проект готовым до его явного апрува.
